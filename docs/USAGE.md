# 사용법

## 처음 설정

1. [Releases](../../../releases/latest)에서 APK를 받아 설치합니다 (Android 10 이상). 이후 업데이트는 앱 위쪽의 "업데이트" 버튼으로 합니다.
2. **설정** 탭 → NovelAI Persistent API Token(`pst-…`)을 넣고 확인. 토큰은 Android Keystore로 암호화해 보관하고 백업에는 넣지 않습니다.
3. 필요하면 장 사이 간격(1.0~2.0초), 자동 저장, 백그라운드 진행, 생성 중 미리보기(스트리밍)를 정합니다.

## 한 번에 여러 장 만들기

1. **프롬프트** 탭에서 고정 / 가변 / 디테일 + 네거티브를 적습니다. 조각(`<이름>`, `<a|b>`)은 장마다 새로 뽑힙니다.
2. 아래 막대에서 장수를 정하고 **생성**. 서버에는 한 장씩 차례로 요청하고, 장 사이에 정한 간격만큼 쉽니다.
3. 생성 중에 화면을 바꾸고 옆의 **+** 를 누르면 그 순간의 설정이 대기열에 들어갑니다. 배치가 바뀔 때와 오류 뒤 다시 보낼 때도 정한 간격을 지킵니다.
4. 앱이 꺼졌다 다시 열리면 끝나지 않은 배치를 이어서 할지 묻습니다. 요청을 보낸 뒤 결과를 못 받은 장은 "확인 필요"로 표시하고, 직접 고르지 않으면 다시 보내지 않습니다(이미 과금됐을 수 있어서).

## 프롬프트 프리셋

- 프리셋을 고른 뒤 고정·디테일·네거티브·생성 설정을 고치면 프리셋 이름 옆에 "수정됨"이 뜹니다. 그 상태로 다른 프리셋을 누르면 "지금 프리셋에 저장 / 새 프리셋으로 저장 / 저장하지 않고 이동"을 묻습니다(가변 프롬프트는 그대로). 프리셋 시트 아래에서 묻지 않고 자동으로 저장하게 바꿀 수 있습니다.
- 프리셋을 옮기거나 "설정 불러오기"로 저장하지 않은 프롬프트가 바뀌면 알림의 **되돌리기**(또는 프리셋 시트 맨 위의 "바뀌기 전 프롬프트로 되돌리기")로 돌아갑니다. 프롬프트·네거티브·생성 설정만 되돌리고, 앱을 닫으면 사라집니다.

## 캐릭터와 출연 슬롯

- **캐릭터** 시트 → 라이브러리에서 캐릭터를 추가합니다. 프롬프트는 고정(알아보게 하는 부분) / 가변 / 디테일 / 네거티브로 나눕니다.
- 변형 그룹(복장·표정·자세…)에 항목을 넣고, 그룹마다 고정 / 무작위(비중) / 순차 / 미사용을 고릅니다.
- **출연 슬롯**: 자리마다 고정 캐릭터, 무작위 후보(캐릭터·폴더, 비중), 순차, 확률(%)을 정합니다. "뽑기 설정"에서 중복 허용, 장마다/배치마다 뽑기, 씬마다 따로 뽑기, 인원 태그 자동 고침을 켭니다.
  - 배치마다 뽑기에서 순차 슬롯은 새 배치마다 다음 후보로 넘어갑니다(앱을 다시 열어도 이어짐). "배치 순서 처음부터"로 첫 후보로 되돌립니다.
- "이번 장 예시"로 실제로 보낼 캡션을 미리 봅니다. **위치 정하기**에서 마커를 끌어 위치를 정합니다(V5 자유, V4·V4.5 5×5 격자).
- 히스토리 그림의 **다시 생성**은 그때 보낸 내용을 그대로, **재추첨 생성**은 그때의 슬롯·변형 설정으로 다시 뽑습니다.

## 씬

**씬** 탭에서 장면별 프롬프트·해상도·출연 캐릭터를 만들고, 씬마다 장수를 예약한 뒤 한 번에 생성합니다.

## i2i · 인페인트

결과·히스토리 그림이나 갤러리 그림을 원본으로 고릅니다. 마스크 편집기에서 두 손가락으로 확대·이동하고, 브러시 크기를 숫자로 정하며, 되돌리기/다시 하기·반전·확장·축소를 씁니다.

## 에셋 제작 (프로젝트 탭)

캐릭터 챗용 이미지(캐릭터 × 의상 × 표정 …)를 빠짐없이 만들고 골라 일정한 이름으로 내보내는 화면입니다.

1. **새 프로젝트** → 캐릭터를 라이브러리에서 고르거나 프로젝트 전용으로 추가하고, 화풍 프롬프트·네거티브·생성 설정을 정합니다("현재 설정 가져오기" 가능).
2. **축**(의상·표정·상황·장소·동작·사용자 정의)과 값(이름·파일용 이름·프롬프트 조각)을 넣습니다. 여러 줄 붙여넣기로 한 번에 넣을 수 있습니다. 캐릭터마다 다른 조각, 제외 규칙, 조합별 덮어쓰기(프롬프트·해상도·장수·목표)도 정할 수 있습니다.
3. **행렬**에서 조합마다 상태(미생성 / 생성 대기 / 생성 중 / 선별 필요 / 채택 / 재생성 필요 / 내보내기 완료)를 봅니다.
4. **생성 계획**: 전체 / 부족한 것만 / 실패한 것만 → 예상 Anlas·시간과 경고를 확인하고 대기열에 넣습니다. 프로젝트 프롬프트가 화면 프롬프트를 대신합니다.
5. **선별**: 조합을 눌러 채택 / 보류 / 탈락. 빠른 선별(한 장씩 크게)도 있습니다. 채택 그림을 바꾸면 같은 칸·다음 버전이 되어 파일 이름과 코드가 유지됩니다.
6. **분류**: 프로젝트 밖에서 만든 히스토리 그림을 규칙·캐릭터 이름·프롬프트 조각으로 조합에 배정합니다(확인 후 적용, 지우지 않음).
7. **내보내기**: 파일·폴더 이름 템플릿(`{character}_{emotion}_{index:02}` 등)과 경로 미리보기, 겹칠 때 처리(번호 붙이기 / 덮어쓰기 / 건너뛰기 / 막기), 변환 프리셋(형식·크기·목표 용량 — 직접 만든 것만), 목록 파일(CSV·JSON·TXT·Markdown)과 이미지 코드 목록을 정합니다.
   - 휴대폰: 갤러리(`Pictures/NAIP/…`, 목록은 `Download/NAIP/…`) 또는 ZIP 파일 하나. 원본은 바꾸지 않습니다.
   - 목표 용량은 최선을 다해 맞추되, 품질 하한 아래로 내리지 않고 못 맞추면 경고합니다.

## 백업 · 복원

설정 → **백업·복원**.

- 가벼운 백업(히스토리 없음) / 전체 백업(히스토리 + 원본) / 직접 고르기. 저장할 곳은 파일 선택 창에서 고릅니다.
- 불러오기: `.naipbackup`, NAIS3 `.nais`, 예전 JSON 백업. 무결성 확인과 미리보기(항목별 개수·겹침)를 본 뒤 덮어쓰기 / 합치기 / 골라서를 정합니다.
- 덮어쓰기 전에는 지금 상태를 자동으로 백업해 두며, 결과 화면이나 백업·복원 시트의 "자동 백업"에서 되돌릴 수 있습니다.
- **NAIS3로 내보내기**: 잃게 되는 것을 먼저 보여 준 뒤 `.nais`로 씁니다.
- 자세한 형식과 호환성은 [DATA.md](DATA.md)를 보세요.

## 저장 공간

설정 → **저장 공간**: 앱이 쓰는 용량·캐시, 갤러리에 저장한 수, 점검(기록과 파일이 맞는지 — 고르기 전에는 지우지 않음), 캐시 비우기.

## 문제가 생기면

- 백그라운드에서 멈추면 앱의 배터리 사용을 "제한 없음"으로 바꾸세요. 포그라운드 서비스로 붙잡아 두지만, 운영체제가 끝까지 실행을 보장하지는 않습니다.
- 생성 중 미리보기에서 중지해도 이미 요청한 장은 비용이 청구될 수 있습니다.
- 저장 공간이 모자라면 생성 전에 묻습니다. 설정 → 저장 공간에서 캐시를 비우거나 히스토리 보관 한도를 조정하세요.
  보관 한도는 즐겨찾기와 프로젝트 그림(탈락 제외)을 빼고 셉니다.
- 업데이트 뒤 히스토리 옮기기가 "읽을 수 없는 그림" 때문에 멈추면, 나머지는 이미 옮겨진 상태입니다. 설정 → 저장 공간에서 그 장을 건너뛰고 마칠 수 있습니다.
- 토큰 저장이나 지우기에 실패하면 알림이 뜹니다. 알림대로 다시 넣거나 다시 지워 주세요.
